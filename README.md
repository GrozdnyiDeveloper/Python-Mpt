# Учебные приложения на Python
В данном репозитории представлены консольные приложения на Python реализованные в рамках учебного процесса. 

**Архив имеет следующее содержимое:**
- Calculator.py - Консольное приложение, представляющее собой простенький калькулятор
- MiniBisness.py - Консольное приложение, предназначенное для управления мини-бизнесом связанным с кулинарией. Приложение хранит данные в локальной БД, имеет простую систему ролевой авторизации и интерактивное меню с бизнес-логикой заказа, склада, скидок и закупок
- NumberOfDays.py - Консольное приложение, которое вычисляет и выводит кол-во дней по месяцам (и в общем в году) в случаи, если все числа месяца выписать в строку и суммировать по отдельности каждое число (то есть например 15 это 1 + 5)
